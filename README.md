# Student Performance Analysis Using Data Analytics

**Student:** Rajeshwari

## 1. Project Overview
This project analyzes school student performance data using Python, data analytics, visualization and a simple AI model.

The project studies factors such as attendance, study hours, assignment performance and previous examination scores to understand their relationship with final student performance.

## 2. Objectives
- Clean and prepare student data.
- Perform exploratory data analysis (EDA).
- Calculate descriptive statistics.
- Visualize student performance.
- Study relationships between academic factors.
- Build a simple Pass/Fail prediction model using Logistic Regression.
- Evaluate the model using accuracy, classification report and confusion matrix.

## 3. Dataset
The notebook creates a small, reproducible school dataset inside the code. Therefore, no separate dataset file is required for the submission.

The dataset contains:
- Student ID
- Gender
- Age
- Class
- Attendance
- Study Hours
- Assignment Score
- Previous Score
- Final Score
- Result
